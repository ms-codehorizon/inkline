# Cast library

One pair of files per set of characters:
- `<name>.py` draws them (one function per character, facing right, neck base at 0,0).
- `<name>.md` is the character sheet stages read: look, default face, never-do rules, voice direction, and the vocabulary of eyes, brows, mouth, head and hands the characters support.

Add a new set as new files. Do not change a set another video uses.
